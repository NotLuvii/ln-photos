# LN Photos

Portfolio website for [@ln._photos](https://www.instagram.com/ln._photos/), automotive photography in New Brunswick, Canada.

Live site: https://notluvii.github.io/ln-photos/

- `index.html`: home page (hero, featured project, portfolio, gallery, services, about, contact)
- `work/<project>/index.html`: one page per project
- `assets/`: styles, script, icons and social preview image
- `img/`: photographs in web sizes (`-sm` 760px, `-lg` 2000px, `-xl` full width)

Static HTML, CSS and JavaScript. No build step, served by GitHub Pages from the `main` branch.

All photographs © LN Photos.
